## 전환 상태 (2026-10-20 코드 반영)
1. 키 이름의 단일 기준은 `data/sources.yaml`의 `env`/`env_legacy`. `capture.service_key()`가 새 이름 → 옛 이름 순으로 읽고, 옛 이름을 쓰면 **이름만** 경고 1회(값은 남기지 않음).
2. `docker-compose.yml` mcp 서비스는 새 이름 7개 + 옛 이름 2개(전환 기간)를 넘긴다. 전환이 끝나면 옛 이름 줄과 `env_legacy`를 지운다.
3. `.env` 인라인 주석은 공백 1칸 이상 + `#`로 잘린다(T-029). 값 안의 `#`(공백 없이 붙은 것)는 그대로.
4. 키 미설정이면 호출하지 않고 원인 `api_auth_error`(ADR-014). 키 값이 로그·fixture·문서에 남지 않는지 마스킹 검사를 유지한다.
