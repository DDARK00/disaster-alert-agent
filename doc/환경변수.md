`DSSP_<용도>_SERVICE_KEY` (행정안전부 재난안전데이터 공유플랫폼). 기상청은 DSSP가 아니므로 `WEATHER_ALERTS_SERVICE_KEY` 유지. 키 값은 `.env`에만 두고 커밋하지 않으며 mcp 컨테이너에만 전달한다.

## 전환 절차 (코드 세션에 인계)
1. `mcp_server/capture.py`의 소스 정의(`env` 필드)와 `docker-compose.yml`의 mcp 서비스 environment를 새 이름으로 바꾼다.
2. 전환 기간에는 새 이름이 없으면 구 이름을 읽는 폴백을 두고, 전환이 끝나면 폴백과 구 이름을 삭제한다.
3. 소스 추가는 `data/sources.yaml`(ADR-013)에서 키 이름을 선언하는 방식으로 통일한다.
4. 키 값이 로그·fixture·문서에 남지 않는지 마스킹 검사를 유지한다.

## 기타 환경변수
LangSmith(`LANGSMITH_*`), LLM(`LLM_*`), 카카오(`KAKAO_REST_API_KEY`, mcp 전용), 데이터 모드(`DATA_MODE`), 포트(`FRONTEND_PORT`)는 `.env.example` 참고.
